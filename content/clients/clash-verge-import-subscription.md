# Clash Verge怎么导入订阅链接？一步一步图文操作

将机场订阅链接成功导入并激活，是使用 Clash Verge Rev 实现代理上网的核心步骤。虽然整体流程只有简单的几步操作，但许多新手常因粘贴带有多余空格、未激活配置文件或遗漏开启系统代理开关而卡在最后一步。按照本教程的标准规范操作，只需两分钟即可完成整个配置流程。

## 第一步：在机场后台获取 Clash 订阅链接

1. 打开浏览器，登录你所购买的机场服务商用户中心仪表盘；
2. 在后台显眼位置（通常在“仪表盘”或“我的订阅”区域）找到“便捷导入”或“复制订阅”按钮；
3. 在弹出的下拉菜单中，**务必选择“复制 Clash 订阅”**。如果服务商提供通用订阅，复制该 URL 亦可；
4. 复制完成后，确保剪贴板中已存入完整的以 `http://` 或 `https://` 开头的长链接。

## 第二步：在 Clash Verge Rev 中下载并解析配置

1. 打开 Clash Verge Rev 客户端主界面，在左侧功能导航栏中点击 **“订阅（Profiles）”**；
2. 在页面顶部显眼的文本输入框中，鼠标右键点击并选择“粘贴”，填入刚才复制的订阅 URL；
3. 点击输入框右侧蓝色的 **“导入（Import）”** 或 **“保存并下载”** 按钮；
4. 此时软件会自动向服务端发起 HTTP 请求并下载 YAML 格式的节点配置。下载成功后，页面中央会生成一张带有机场名称、节点总数及剩余流量信息的配置卡片。

## 第三步：选中激活配置卡片

很多新手最容易忽视的步骤是“卡片激活”：
- 下载成功后，该卡片尚未生效；
- 必须用鼠标**左键单击该配置卡片**。卡片边缘出现高亮边框或显示绿色激活对勾标记时，才表示该订阅配置已正式装载到底层内核中。

## 第四步：选择节点并开启系统代理

1. 点击软件左侧导航栏的 **“代理（Proxies）”**，进入节点选择面板；
2. 确保顶部模式处于 **“规则（Rule）”** 状态；
3. 在“节点选择”或“PROXY”策略组中，展开节点列表，点击选中一个延迟较低的节点（如中国香港或日本节点）；
4. 点击左侧导航栏的 **“设置（Settings）”**，找到 **“系统代理（System Proxy）”** 开关并将其拨动为**开启状态**；
5. 打开浏览器，输入跨国技术官网测试，网页顺畅打开即代表配置圆满成功。

## 订阅导入与连通标准排查步骤表

| 排查阶段 | 操作目标 | 成功状态判断标准 | 异常时的应对措施 |
| :--- | :--- | :--- | :--- |
| 第一阶段 | 粘贴并点击导入 | 出现新的配置卡片与节点总数 | 若报错检查链接完整性或网络连接 |
| 第二阶段 | 激活配置卡片 | 卡片高亮显示，无报错弹窗 | 右键卡片点击“刷新”重新拉取 |
| 第三阶段 | 代理组选择节点 | 节点测速显示绿色毫秒数值 | 若显示超时变红，切换同区域其他备用 |
| 第四阶段 | 开启系统代理 | 系统代理开关变绿，状态栏托盘变色 | 检查Windows设置中代理端口是否一致 |

## 养成定期更新订阅的良好习惯

为了同步服务商维护新增的线路或修复失效机房，建议右键点击该订阅卡片，选择“编辑（Edit）”，将自动更新间隔（Update Interval）设置为 `720` 分钟（即 12 小时一次），让客户端在后台自动拉取最新节点信息。

## 订阅导入常见疑问

**Q：点击导入后一直提示“Network Error”或下载失败？**  
A：检查复制的链接是否完整。若确认链接无误，可能是本地网络阻断了服务商的订阅域名，可尝试用手机热点拉取一次，或暂时借用其他可用网络下载。

**Q：系统代理开关打开了，但浏览器依然无法打开网页？**  
A：检查电脑本地时间是否准确同步，并确认浏览器未安装其他冲突的代理扩展插件（如 SwitchyOmega）。
