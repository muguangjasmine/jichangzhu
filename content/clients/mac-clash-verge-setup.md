# Mac苹果电脑Clash Verge Rev配置与系统权限指南

在苹果 macOS 操作系统下，**Clash Verge Rev** 凭借对 macOS 原生设计语言的完美契合、对 Apple Silicon（M1/M2/M3/M4 系列）芯片的原生硬件指令集支持，以及强大的内核管理能力，已成为 Mac 用户进行代理网络配置的最佳工具。由于 macOS 严苛的沙盒安全机制，用户在首次安装与启用系统权限时需掌握正确的设置方法。

## 第一步：区分芯片架构并获取正确安装包

苹果 Mac 电脑目前存在两大硬件阵营，下载安装包时切勿选错：
1. **Apple Silicon 芯片（推荐主力）：** 采用 M1、M2、M3、M4 系列自研芯片的 Mac 设备，必须下载文件名带有 **`aarch64.dmg`** 或 **`arm64.dmg`** 的安装镜像包；
2. **Intel 处理器（老款机型）：** 较早期的 Intel 酷睿处理器的 Mac 电脑，请下载带有 **`x64.dmg`** 的安装镜像包；
3. 打开下载的 `.dmg` 镜像文件，将 Clash Verge 图标顺畅拖拽至右侧的 **“Applications（应用程序）”** 文件夹中完成安装。

## 第二步：处理“已损坏无法打开”或未签名安全提示

在首次从“应用程序”启动软件时，macOS Gatekeeper 安全系统可能会弹出警示：“无法打开，因为 Apple 无法检查其是否包含恶意软件”：
1. 点击提示框的“取消”；
2. 打开 Mac 的 **“系统设置（System Settings）” - “隐私与安全性（Privacy & Security）”**；
3. 向下滚动到“安全性”栏目，你会看到一条被拦截记录：“已阻止使用 Clash Verge”；
4. 点击右侧的 **“仍要打开（Open Anyway）”** 按钮，并在弹出窗口中输入 Mac 开机登录密码即可顺利放行。

## 第三步：导入机场订阅并选择低延迟节点

1. 在 Mac 浏览器中登录你的机场后台用户中心，复制专属的 Clash 订阅链接；
2. 打开 Clash Verge Rev，点击左侧边栏的 **“订阅（Profiles）”**；
3. 在上方文本输入框中粘贴订阅 URL，点击右侧的 **“导入（Import）”**；
4. 订阅下载完成后，**用鼠标左键单击该配置卡片**将其设为当前活动配置；
5. 点击左侧边栏的 **“代理（Proxies）”**，确认处于“规则（Rule）”模式，并点选一个低延迟的亚太可用节点。

## 第四步：开启系统代理与授予辅助功能权限

1. 点击软件左侧边栏的 **“设置（Settings）”**；
2. 拨动开启 **“系统代理（System Proxy）”** 开关；
3. 此时 Mac 顶部菜单栏会出现 Clash Verge 的状态图标，Safari 及 Chrome 浏览器即可无缝建立代理网络；
4. **TUN 模式系统扩展授权（选配）：** 如果你需要开启 TUN 模式接管终端命令行，Mac 系统会弹出“网络扩展想要过滤网络流量”的系统弹窗，此时必须点击 **“允许（Allow）”** 并完成管理员触控 ID 或密码验证。

## Mac 版客户端关键环节自检表

| 配置步骤 | 关键操作目标 | 常见报错与排查措施 |
| :--- | :--- | :--- |
| 安装包选型 | M系列选 aarch64，Intel选 x64 | 选错架构将提示不兼容或通过 Rosetta 转译耗电 |
| 安全放行 | 在系统设置中点击“仍要打开” | 避免误以为软件包损坏而反复重复下载 |

## Mac 笔记本随身携带休眠唤醒技巧

由于 MacBook 经常处于盒盖休眠状态，部分老旧核心可能在唤醒后出现网络短暂死锁。Clash Verge Rev 内置了休眠唤醒重置钩子，只要保持软件常驻后台，开盖瞬间即可自动无感恢复网络连接。

## Mac 客户端常见问答

**Q：Mac 端开启代理后，为什么自带的隔空投送（AirDrop）搜不到人了？**  
A：默认的标准规则模式不会影响隔空投送。如果误开了某些强制全局模式，请检查分流规则，确保局域网组播协议未被拦截。

**Q：Mac 终端（Terminal / iTerm2）输入 curl 命令怎么走代理？**  
A：最优雅的做法是在 Clash Verge 设置中安装服务模式并打开“TUN 模式”，终端无需任何额外配置即可自动走代理规则。

需要开启 TUN 模式的用户，请参阅 [Clash Verge 系统代理与 TUN 模式开启设置教程](/clients/clash-verge-system-proxy-tun/)；Windows 端配置可参考 [Clash Verge Windows 教程](/clients/clash-verge-windows-install/)。
