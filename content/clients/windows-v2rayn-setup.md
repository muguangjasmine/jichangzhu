# Windows下v2rayN客户端订阅导入与节点切换教程

在 Windows 平台上，除了基于 Electron 框架编写的图形化客户端 Clash Verge Rev 之外，基于原生 .NET 编写的 **v2rayN** 凭借极其轻量的内存占用、卓越的启动速度与直观的列表式操作，一直是广大资深工程师与低配置办公电脑用户的首选备用工具。熟练掌握 v2rayN 的配置，能够为你的 PC 提供坚固的双重网络保障。

## 第一步：下载包含 Core 核心的完整软件包

v2rayN 本身仅是一个图形操作外壳，其真正的网络转发需要依托底层的 Xray-core 或 V2Ray-core 运行：
1. 访问 GitHub 官方仓库搜索 `2dust/v2rayN`，进入 Releases 页面；
2. **下载挑选重点：** 初学者务必下载文件名形如 **`v2rayN-With-Core.zip`** 或包含 Xray-core 的完整压缩包，避免下载纯界面版本导致提示“找不到内核核心文件”；
3. 将下载的 ZIP 压缩包解压到一个固定的英文路径文件夹下（例如 `D:\Program Files\v2rayN`），切勿解压在带有特殊字符的临时目录下；
4. 运行文件夹内的 `v2rayN.exe`，系统右下角托盘区会出现经典的深蓝色大写“V”图标。

## 第二步：添加机场订阅分组并拉取节点

1. 在 v2rayN 主窗口顶部菜单栏中，点击 **“订阅分组”**，在下拉菜单中选择 **“订阅分组设置”**；
2. 在弹出的窗口中，点击左上角 **“添加”**；
3. **输入配置详情：**
   - **别名（Remarks）：** 填入你的机场品牌名字；
   - **可选地址（Url）：** 粘贴从机场后台复制的通用或 V2Ray 订阅链接；
4. 点击右下角 **“确定”** 保存分组；
5. 返回顶部菜单栏，再次点击 **“订阅分组”**，选择 **“更新订阅（不通过代理）”**；
6. 稍等数秒，主界面列表中将整齐展示服务商的所有节点服务器。

## 第三步：节点可用性测速与设为主节点

1. 在节点列表中按下键盘快捷键 `Ctrl+A` 全选所有节点；
2. 鼠标右键点击任意节点，在弹出菜单中选择 **“测试服务器连接与延迟”**（或点击顶部工具栏的“测试-测试服务器延迟Real Ping”）；
3. 观察最后一列的“延迟”数据，选中一个绿色可用节点；
4. 鼠标右键点击该节点，选择 **“设为主节点（Enter）”**，该节点文字将高亮显示。

## 第四步：正确配置底部系统代理与路由规则

v2rayN 的代理开关位于主界面底部状态栏，新手切勿忽略：
1. **自动配置系统代理：** 在底部“系统代理”下拉框中，将状态由“清除系统代理”切换为 **“自动配置系统代理”**，此时托盘区的 V 图标会由蓝色变为**鲜艳的红色**，代表系统代理已正式生效；
2. **路由分流规则：** 底部右侧的“路由”下拉框，必须选择 **“绕过大陆（Whitelist）”** 或预设的绕过中国大陆 IP 规则，确保国内网站走本地宽带直连。

## v2rayN 关键配置与快捷操作速查表

| 操作项 | 菜单路径 | 正常生效特征 | 注意事项 |
| :--- | :--- | :--- | :--- |
| 添加订阅 | 顶部菜单 - 订阅分组设置 | 填入 URL 并点击保存 | 必须在添加后执行“更新订阅” |
| 节点激活 | 选中节点按下键盘 Enter 键 | 节点名称字体变粗或变蓝 | 每次只能将一个节点设为主活动节点 |
| 代理开关 | 底部状态栏 - 系统代理 | 托盘图标由蓝色变红 | 关闭时记得切换为“清除系统代理” |
| 路由分流 | 底部状态栏 - 路由规则 | 选“绕过大陆”直连国内 | 误选“全局”将导致微信图片加载慢 |

## 退出软件前的必要安全操作

在使用 v2rayN 过程中，若需要退出软件，**必须先右键托盘图标，选择“清除系统代理并退出”**。如果直接在任务管理器中强制杀死进程，会导致 Windows 系统代理设置未被清除，进而引发电脑浏览器全网无法打开网页的故障。

## v2rayN 常见疑问

**Q：为什么点击“更新订阅”提示无法解析主机或网络超时？**  
A：检查订阅链接是否被本地运营商 DNS 污染，可先在底部开启系统代理并借用已有节点，选择“更新订阅（通过代理）”尝试更新。

**Q：v2rayN 与 Clash Verge 可以在同一台电脑上共存吗？**  
A：完全可以共存，但**绝对不要同时开启两者的系统代理开关**，同一时刻只运行其中一款软件，避免本地端口发生冲突。

若退出软件后电脑连不上网，请参阅 [Win系统代理残留一键修复指南](/troubleshooting/system-proxy-reset/)；了解主推客户端请查阅 [Clash Verge Windows 配置指南](/clients/clash-verge-windows-install/)。
