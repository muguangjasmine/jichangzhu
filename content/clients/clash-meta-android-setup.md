# 安卓手机Clash Meta下载安装与订阅导入指南

在 Android 移动端生态中，**Clash Meta for Android**（简称 CMFA）是目前维护最活跃、内核特性最前沿的代理应用之一。它全面继承了开源 Mihomo 内核的高级分流能力与新一代协议支持，同时针对安卓系统的电量与多任务管理进行了深度优化。按照本指南操作，即可在安卓手机上实现轻快、稳定的网络体验。

## 第一步：下载匹配手机 CPU 架构的 APK 安装包

为了保障数据安全，请务必从官方开源渠道获取安装文件：
1. 访问 GitHub 官方仓库搜索 `MetaCubeX/ClashMetaForAndroid`，进入 Releases 页面；
2. **挑选正确架构：** 绝大多数近五年内发布的现代安卓智能手机均采用 64 位 ARM 处理器，请认准并下载文件名包含 **`arm64-v8a.apk`** 的安装包；
3. 如果是老旧设备或特定模拟器，再考虑下载 `armeabi-v7a` 或 `universal` 通用版本；
4. 下载后点击安装，若系统提示“来自未知来源的应用”，点击允许继续安装。

## 第二步：导入并激活机场订阅配置

1. 打开手机浏览器，登录你的机场后台用户中心，找到“一键导入”或“复制订阅链接”，复制完整的 Clash 订阅 URL；
2. 启动 Clash Meta for Android，在首页点击 **“配置（Profiles）”** 选项；
3. 点击页面右上角的 **“+（加号）”**，在弹出的导入方式中选择 **“从 URL 导入”**；
4. **填写导入信息：**
   - **名称（Name）：** 随意填写，例如你的机场名称；
   - **URL：** 长按输入框，粘贴刚才复制的订阅链接；
   - **自动更新间隔：** 建议输入 `720` 或 `1440` 分钟（即 12 小时或 24 小时）；
5. 点击右上角 **“保存（软盘图标）”**，软件将自动联网拉取配置；
6. 返回配置列表页，**单选勾选刚才添加的配置卡片**，使其右侧呈现选中高亮状态。

## 第三步：启动连接与系统 VPN 权限授予

1. 返回软件主界面，点击中心或顶部显眼的 **“启动（Start）”** 按钮；
2. 首次启动时，Android 系统会弹出安全提示窗口：“Clash Meta 想设置一个 VPN 连接以监控网络流量”；
3. 此处必须点击 **“确定（OK）”**，手机状态栏出现小钥匙或 VPN 图标，代表底层代理管线已成功建立；
4. 点击主界面的“代理（Proxy）”，确认处于“规则（Rule）”模式，并手动挑选一个延迟较低的节点即可开始上网。

## 第四步：彻底防止后台被系统自动断连

国产安卓系统的后台电量清理策略极其严格，若不做以下设置，几分钟后代理进程就会被系统自动杀死：
- **锁定后台任务：** 打开手机多任务后台切换界面，找到 Clash Meta 卡片，下拉并点击小锁图标将其“加锁”；
- **允许后台无限制耗电：** 进入手机“系统设置-应用管理-Clash Meta-电池与省电”，将后台策略由“智能限制”改为 **“无限制”** 或 **“允许后台高耗电运行”**；
- **自启动权限放行：** 在权限管理中，勾选允许应用“开机自启动”与“后台关联启动”。

## Clash Meta 安卓端常见问答

**Q：开启代理后，手机顶部的 WiFi 图标旁边出现感叹号怎么办？**  
A：这是因为手机系统向谷歌连通性检测服务器发送探测包由于未在直连名单中被拦截。只要浏览器能正常打开网页，完全无需理会感叹号。

**Q：如何在安卓端只让浏览器走代理、其他所有 App 都不走？**  
A：进入 Clash Meta 的“设置-网络”，打开“分应用代理”开关，将模式改为“黑名单/白名单”，仅勾选你需要代理的浏览器应用即可。

手机无法成功拉取订阅链接的用户，请阅读 [手机无法导入订阅链接排查指南](/troubleshooting/phone-subscription-wont-import/)；备用客户端设置请参考 [安卓 sing-box 配置指南](/clients/android-singbox-guide/)。
