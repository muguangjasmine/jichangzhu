# Windows安装Clash Verge Rev保姆级步骤：从零到初始化

在原版 Clash for Windows 停更之后，基于现代化技术重构的 **Clash Verge Rev** 迅速成为 Windows 平台上最主流、功能最完备的开源代理客户端。它不仅完美支持 Mihomo（原 Clash.Meta）高级内核，还提供了清爽直观的中文用户界面。掌握规范的安装流程，能够避免启动白屏、闪退及缺少系统运行库等常见新手故障。

## 第一步：检查并安装微软 WebView2 核心运行库

Clash Verge Rev 采用现代 Web 前端技术渲染图形交互界面，其底层深度依赖微软官方提供的 **WebView2 运行时**：
1. **系统预装检查：** 多数较新的 Windows 11 系统已内置该组件，但很多 Windows 10 或精简版系统并未预装；
2. **下载与补全：** 若打开软件提示找不到组件或直接白屏，请直接访问微软官方网站，搜索“WebView2 Evergreen Standalone Installer”，下载安装包并以管理员身份完成安装；
3. **完成安装：** 安装成功后无需重启电脑，即可确保后续客户端界面的顺畅加载。

## 第二步：获取正版客户端安装包

为了设备系统与网络凭据的安全，切勿在非官方网盘或各类破解下载站下载软件：
- **官方开源仓库：** 前往 GitHub 平台搜索 `clash-verge-rev/clash-verge-rev`，进入右侧的 **Releases** 稳定版本发布区；
- **架构版本挑选：** 普通 64 位 Windows 电脑请选择 `Clash.Verge_x.x.x_x64-setup.exe` 安装版；如果不想写入注册表，可选择 `x64_portable.zip` 便携解压版；
- **运行安装程序：** 双击安装包，建议按照默认路径安装至系统盘，并勾选“为所有用户安装”。

## 第三步：首次启动与基础偏好设置

首次运行 Clash Verge Rev 时，建议完成以下核心初始配置：
1. **中文语言确认：** 软件通常会自动识别系统区域并显示简体中文。若显示英文，点击左侧底部齿轮图标（Settings），在“Language”下拉菜单中选择“zh-CN”；
2. **内核模式设置：** 在设置页面确认内核切换为 **Clash Meta（Mihomo）**，该内核对现代复杂分流规则与新协议拥有极佳的兼容性；
3. **开机自启动开关：** 根据个人日常使用习惯，可勾选“开机自启动”与“静默启动至系统托盘”，确保日常办公无需每次手动打开。

## 安装核心环节与排错自检表

| 安装步骤 | 核心操作点 | 常见报错与排错方案 |
| :--- | :--- | :--- |
| 系统依赖库 | 安装微软 WebView2 Evergreen | 软件启动白屏或提示缺少 msedgewebview2.exe |
| 安装包架构 | 严格选择 64位 (x64) 安装包 | 误下载 arm64 导致系统提示不兼容无法运行 |
| 防火墙拦截 | Windows Defender 提示未知应用 | 点击“更多信息”，选择“仍要运行”并放行 |
| 托盘常驻 | 勾选“关闭主窗口时最小化到托盘” | 点击右上角红叉直接误退出了代理后台进程 |

## 安装完毕后的下一步

完成软件安装与基础初始化后，客户端此时尚不包含任何可用的网络节点。接下来你需要前往机场后台复制订阅链接，并将其导入至软件的“订阅（Profiles）”模块中以建立网络连接。

## Clash Verge 安装常见问答

**Q：安装时 Windows Defender 提示危险并拦截怎么办？**  
A：开源代理软件由于涉及系统网络代理接管与虚拟网卡驱动，常被杀毒软件误报。认准官方 GitHub Releases 下载的安装包，在提示页面点击“更多信息”并选择“仍要运行”即可。

**Q：安装便携版和安装版有什么实际功能区别吗？**  
A：核心代理功能完全一致。安装版便于自动关联系统协议与卸载管理；便携版则将配置文件存放在当前文件夹，方便放在 U 盘随身携带使用。
