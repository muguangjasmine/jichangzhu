# 电脑与手机客户端怎么定时更新节点订阅列表？

在网络代理的使用过程中，机场服务商绝非一成不变的静态实体。为了应对国际骨干海缆故障、机房日常硬件维护或网络出口阻断，服务商的技术团队会定期在后台轮换服务器 IP、添加全新优化线路或调整节点协议端口。如果你导入订阅后连续数周甚至数月从未更新，旧的节点 IP 便会逐步失效变红。掌握多端自动化定时更新订阅的技巧，能让你的节点列表时刻保持新鲜可用。

## 为什么不能等到断网了才想起来手动更新？

许多新手的习惯是“只要能用就永远不点更新，直到某天全线飘红断网才手忙脚乱”：
- **死锁陷阱：** 当你的旧节点全部因长期不更新而失效时，你的客户端此时已彻底断网。如果你未关闭系统代理直接点击“更新订阅”，更新请求本身会被死掉的代理管线拦截，陷入“因为没网所以更新不了，因为更新不了所以没网”的恶性死锁；
- **自动化静默更新的优势：** 在当前节点依然健康通畅的时刻，让客户端在后台自动拉取未来备用节点的最新 IP，即使个别机房发生突发故障，系统也能瞬间无感切换到最新备用线路上。

## Windows 端：Clash Verge Rev 自动定时更新设置

1. 打开 Clash Verge Rev 客户端，点击左侧功能栏的 **“订阅（Profiles）”**；
2. 找到你当前正在使用的主力订阅卡片，鼠标右键单击它，在弹出的上下文菜单中选择 **“编辑（Edit）”**；
3. 在弹出的配置属性编辑弹窗中，找到 **“更新间隔（Update Interval）”** 选项；
4. **填入数值：** 单位为**分钟**。建议输入 `720`（即每 12 小时自动拉取一次）或 `1440`（即每 24 小时自动拉取一次）；
5. 点击“保存”完成设置。软件后台的定时任务调度器将在后台静默拉取并平滑重载配置，期间完全不中断你的正常上网。

## 苹果 iOS 端：Shadowrocket（小火箭）自动更新设置

小火箭在 iOS 系统上同样支持贴心的免打扰自动更新机制：
1. 打开 Shadowrocket，点击底部右下角的 **“设置（Settings）”**；
2. 向下滑动找到并进入 **“订阅（Subscribe）”** 菜单；
3. **开启关键开关：**
   - 勾选 **“打开时更新（Update on Open）”**：每次你手动点开小火箭 App 时，它会自动在后台检测并刷新最新节点；
   - 勾选 **“自动后台更新（Background Update）”**：利用 iOS 系统的后台刷新机制在电量充裕时自动完成节点同步。

## 安卓 Android 端：Clash Meta 定时更新设置

1. 打开 Clash Meta for Android，点击主页的 **“配置（Profiles）”**；
2. 找到你的订阅配置卡片，点击右侧的三颗小圆点菜单，选择 **“修改（Edit）”**；
3. 找到 **“自动更新间隔”** 字段，填入 `720` 分钟并保存；
4. 确认在安卓手机的“应用权限管理”中，授予了 Clash Meta “允许后台唤醒”的必要权限。

## 自动更新时的必要安全提示

自动更新并不意味着频率越高越好。切勿将更新间隔设置为几分钟一次，频繁高密度的并发 HTTP 请求不仅会大量浪费手机后台电量，而且极易触发机场服务商 API 网关的防恶意刷新风控机制，导致你的用户 Token 被临时限流封禁数小时。设定在 **12至24小时** 一次最为科学合理。

## 订阅更新常见问答

**Q：更新订阅时提示“401 Unauthorized”未授权怎么办？**  
A：这说明你的订阅链接 Token 已被重置或套餐已到期，需登录机场后台重新复制最新的订阅链接。

**Q：更新订阅会把我个人自定义的规则覆盖掉吗？**  
A：如果使用的是普通纯订阅卡片，更新会直接拉取服务商最新的完整规则。需要保留自定义规则的用户，建议使用 Clash Verge 的 Script/Merge 扩展脚本功能。
