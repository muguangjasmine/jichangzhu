# 机场不能连接怎么办？五步快速排查连不上网故障

在日常使用代理网络的过程中，“刚才还好好的，突然所有网页都打不开了”是新手最常遭遇的高频困扰。面对断网，盲目地反复卸载重装客户端往往徒劳无功，甚至可能破坏原有的正确网络栈。遵循严谨的“从底层到应用层”排查逻辑，只需五步即可快速定位故障根源并恢复通信。

## 第一步：排查本地系统时间是否准确同步（隐蔽故障首因）

这是引发所有加密协议握手失败最容易被忽视的头号杀手：
- **技术原理：** 现代加密代理协议（如 VMess、Trojan、Shadowsocks 等）严重依赖基于绝对时间戳的重放攻击防护机制。如果本地设备时间与标准原子钟时间偏差超过 **60 秒**，服务器会出于安全防护机制直接拒绝解包，将你的数据包直接丢弃；
- **排查步骤：**
  - 在 Windows 任务栏右键点击时间，选择“调整日期和时间”；
  - 确认开启“自动设置时间”，并手动点击 **“立即同步（Sync now）”** 按钮；
  - 手机端同样进入“设置-通用-日期与时间”，开启“自动设置”。

## 第二步：检查客户端系统代理开关与端口占用

许多新手以为把软件打开就算启动了，实则遗漏了系统级接管开关：
1. 打开 Clash Verge Rev，在左侧导航栏的 **“设置”** 中，检查 **“系统代理（System Proxy）”** 开关是否真正处于开启状态；
2. **检查端口冲突：** 默认端口通常为 `7890` 或 `7897`。如果电脑中同时运行了其他加速器、虚拟机或抓包软件，会导致端口被强行抢占。可在设置中尝试将端口手动修改为较冷门的数值（如 `8899`）。

## 第三步：执行节点延迟测试，排查单点故障

1. 在客户端进入“代理（Proxies）”面板，点击右下角的测速小飞机或闪电图标执行全员测速；
2. **观察测试结果：**
   - 若只有少数节点变红超时，说明属于个别机房临时波动，手动切换至绿色的可用节点即可；
   - 若全部节点整齐划一显示红色超时或 0ms，请立即进行下一步排查。

## 第四步：检查套餐到期状态与流量配额

登录机场官网用户中心，核对两项核心指标：
- **到期时间：** 确认套餐是否已超出有效服务期限；
- **剩余流量：** 确认本月配额是否已被大文件下载或后台自动更新意外耗尽。若流量归零，需在后台充值重置配额。

## 第五步：排查局域网防火墙与杀毒软件拦截

若在公司局域网、校园网或开启了严格第三方卫士的电脑上：
- 局域网网关可能对高端口实施了严格屏蔽；
- 尝试将电脑切换至手机 4G/5G 移动热点测试。若切换手机热点后瞬间连通，说明是原本地 WiFi 网络防火墙的端口屏蔽所致。

## 五步断网排查顺序与快速行动指南表

| 排查次序 | 关键检查对象 | 判定标准 | 快速解决措施 |
| :--- | :--- | :--- | :--- |
| **步骤一** | 本地系统时间戳 | 偏差是否超过60秒 | 点击 Windows“立即同步”校准时间 |
| **步骤二** | 客户端系统代理开关 | 开关是否为绿色开启 | 拨动系统代理开关，检查端口占用 |
| **步骤三** | 代理节点列表测速 | 是否存在绿色延迟数值 | 挑选低于100ms的健康节点切换 |
| **步骤四** | 机场后台账户状态 | 流量是否归零/套餐到期 | 续费套餐或购买当月流量重置加油包 |
| **步骤五** | 本地宽带局域网环境 | 手机热点是否能跑通 | 切换网络，排查公司/校园网络端口封锁 |

## 常见疑问解答

**Q：为什么测速全部显示红色，但微信依然能正常发文字？**  
A：因为微信走的是本地国内直连网络，系统代理即便失效完全不影响国内流量，这恰恰证明是代理服务器或境外出口链路出现了阻断。

**Q：突然全线变红，会不会是机场彻底跑路了？**  
A：先访问机场官网后台或官方 Telegram 交流群。若官网能正常打开且公告栏有突发光缆维护通知，耐心等待官方机房恢复即可。

若关掉客户端后电脑无法浏览正常国内网页，请参阅 [Win系统代理残留一键修复指南](/troubleshooting/system-proxy-reset/)；若需排查订阅刷新问题，可参考 [订阅更新失败故障排查教程](/troubleshooting/subscription-update-failed/)。
