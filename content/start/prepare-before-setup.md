# 开始配置前需要准备什么？新手必备准备清单

在购买机场套餐并着手导入订阅之前，提前做好本地设备的环境准备，能够极大降低后续报错、连不上网或软件冲突的概率。很多新手在刚买完服务后由于系统缺少必要组件或下错了客户端版本，往往在配置第一步就陷入困惑。按照本清单逐一核对准备，可确保整个导入流程顺畅无阻。

## 硬件与操作系统环境核查

确保你的设备满足主流开源代理客户端的基本运行环境要求：
- **Windows 用户：** 推荐 Windows 10 或 Windows 11 64位系统。务必提前安装微软官方提供的 **WebView2 运行时（Evergreen Standalone Installer）**。当前的现代化客户端如 Clash Verge Rev 深度依赖该系统组件渲染图形界面，缺少该组件会导致软件启动闪退或白屏；
- **苹果 macOS 用户：** 确认芯片架构是 Apple Silicon（M系列）还是 Intel 芯片，下载客户端安装包时需严格对应相应的 CPU 架构版本；
- **安卓 Android 用户：** 确保手机允许安装来自第三方未知来源的 APK 安装包，并在系统设置中授予必要的网络与 VPN 建立权限；
- **苹果 iOS 用户：** 必须提前准备一个非中国大陆地区的 Apple ID，以便在境外 App Store 中购买下载 Shadowrocket（小火箭）。

## 软件客户端下载渠道准备

为了设备与网络数据安全，切勿在来历不明的第三方网盘、破解软件站或社交群文件中下载客户端安装包。正规下载渠道包括：
1. **GitHub 官方开源 Releases：** 获取 Clash Verge Rev、v2rayN、sing-box 或 Clash Meta for Android 的原生编译包；
2. **官方应用商店：** 仅通过苹果美区/外区 App Store 获取正版 Shadowrocket，认准开发者名称；
3. **服务商后台提供的客户端直链：** 部分信誉良好的机场会在使用文档中镜像官方开源发布包，方便本地无法直接访问 GitHub 的新手下载。

## 配置前必备软硬件与工具检查表

| 设备平台 | 推荐首选客户端 | 关键前置准备项 |
| :--- | :--- | :--- |
| Windows PC | Clash Verge Rev | 必须安装微软 WebView2 运行库 |
| macOS 苹果电脑 | Clash Verge Rev (Mac版) | 授予系统网络扩展与辅助功能权限 |

## 本地网络环境自检与冲突排查

在首次启动代理软件之前，务必完成以下自检：
- **退出冲突软件：** 彻底退出电脑中其他可能占用本地 7890 端口的旧代理程序或网络加速器；
- **校准系统时间：** 进入系统设置，将日期与时间设置为“自动同步”。现代加密通信协议对时间戳要求极其严苛，本地系统时间一旦与国际标准时间偏差超过 60 秒，将直接导致所有节点 TLS 握手失败。

## 准备阶段新手问答

**Q：电脑没有管理员权限可以正常使用代理软件吗？**  
A：普通的浏览器系统代理模式通常不需要系统管理员权限；但如果要启用深度接管全部网络流量的 TUN 虚拟网卡模式，则必须以管理员身份运行客户端并安装服务组件。

**Q：为什么华为或部分安卓手机会频繁杀掉后台代理？**  
A：国产定制安卓系统省电机制较为激进，需在“应用管理-电池优化”中将客户端设置为“允许后台高耗电”或“无限制”，并在后台任务卡片上加锁。

准备工作就绪后，Windows 用户可立即阅读 [Clash Verge Windows 安装保姆级步骤](/clients/clash-verge-windows-install/)；移动端用户可查阅 [安卓 Clash Meta 安装与订阅导入教程](/clients/clash-meta-android-setup/)。
