# 规则模式、全局模式与直连模式的区别与日常选择

无论是在电脑端的 Clash Verge Rev、v2rayN，还是在手机端的 Shadowrocket 小火箭中，用户在启动代理时都会面临三种核心路由运行模式的选择：**规则模式（Rule）、全局模式（Global）与直连模式（Direct）**。很多初学者因为不理解其分流机制，常常在遇到网页打不开时胡乱切换为全局模式，导致微信图片卡顿、国内 App 频报异地风险。透彻理解这三种模式的差异，是实现流畅上网的必备功课。

## 模式一：规则模式（Rule / Config）—— 99% 场景下的默认黄金选择

规则模式是现代代理软件的灵魂所在。其核心逻辑是“**各行其道，智能分流**”：
- **分流依据：** 客户端内置了一套庞大的域名与 IP 地址数据库（如 GeoIP 与社区路由规则集）；
- **执行动作：**
  - 当你访问国内网站（如百度、淘宝、哔哩哔哩、微信服务器）时，客户端判断该目标属于国内网络，自动走**本地宽带直连**；
  - 当你访问被屏蔽的海外技术文档、GitHub 仓库或跨国学术站点时，客户端自动将数据包路由到你选中的**代理服务器节点**；
- **核心收益：** 既保证了海外网站的瞬时打开，又完全不浪费宝贵的机场套餐流量，同时国内应用依然享受本地千兆光纤的零延迟体验。

## 模式二：全局模式（Global / Proxy）—— 仅限特殊排错的临时手段

全局模式是极其粗暴的“**一刀切**”机制：
- **执行动作：** 彻底屏蔽所有的分流判断规则，整台电脑发出的**每一个网络请求全部强制经由代理服务器中转**；
- **致命弊端：**
  - **白白浪费套餐流量：** 本地微信刷视频、看国内网页的所有流量都会疯狂扣除你的机场配额；
  - **严重减缓国内访问：** 访问本地原本几毫秒的国内网页，却硬要绕道香港或日本服务器兜一圈，导致国内 App 加载极慢；
  - **触发安全风控：** 登录国内网上银行或重要企业协同平台时，会被系统识别为境外异常 IP 登录，极易触发二次验证或账户风控；
- **唯一合理用途：** 当某个冷门海外技术新站未被收录进内置规则库时，可临时切换到全局模式测试连通性，测试完毕后必须立刻切回规则模式。

## 模式三：直连模式（Direct）—— 软件常驻但完全不走代理

- **执行动作：** 所有的网络数据包 100% 走本地真实网络直发，代理节点完全处于待命休眠状态；
- **适用场景：** 当你在进行高吞吐量的本地内网测速，或者在确信当前几个小时完全不需要访问任何海外网络、但又懒得彻底关闭客户端软件时使用。
